1. APLICAR E VALIDAR
--------------------

$repo = "C:\Users\TH\Documents\GitHub\estoque-superinfra"
$pacote = "$HOME\Downloads\atualizacao-70-permissao-cadastro-todos-estoques.zip"
$aplicador = "$HOME\Downloads\APLICAR-ATUALIZACAO-70.ps1"

if (!(Test-Path -LiteralPath $repo -PathType Container)) {
    throw "Projeto não encontrado em: $repo"
}

if (!(Test-Path -LiteralPath $pacote -PathType Leaf)) {
    throw "Pacote não encontrado em: $pacote"
}

if (!(Test-Path -LiteralPath $aplicador -PathType Leaf)) {
    throw "Aplicador não encontrado em: $aplicador"
}

Unblock-File -LiteralPath $aplicador

Set-ExecutionPolicy `
    -Scope Process `
    -ExecutionPolicy Bypass `
    -Force

& $aplicador `
    -Repo $repo `
    -Zip $pacote

3. REDEPLOY
-----------

A atualização possui backend e frontend.

1. concluir o push no GitHub;
2. fazer redeploy do backend no Render;
3. aguardar a API ficar saudável;
4. fazer redeploy do frontend na Vercel;
5. sair e entrar novamente na conta testada;
6. pressionar Ctrl+F5.

Teste do Render:

Invoke-RestMethod `
    -Method Get `
    -Uri "https://stockflow-backend-6gxl.onrender.com/api/health"

4. CONCEDER A PERMISSÃO
-----------------------

Após os redeploys:

1. entrar como administrador;
2. abrir Administração;
3. abrir Usuários e permissões;
4. editar o usuário;
5. abrir Permissões especiais;
6. marcar Cadastrar material em todos os estoques;
7. salvar.

O usuário deve sair e entrar novamente, ou aguardar a atualização automática
das permissões da sessão.

5. TESTE CONTROLADO
-------------------

Conta sem permissão:

- a opção Todos os estoques não deve aparecer;
- cadastro em um estoque específico deve funcionar;
- tentativa manual pela API deve receber 403.

Conta com permissão:

- a opção Todos os estoques deve aparecer;
- o material deve ser criado uma única vez;
- cada estoque autorizado deve aparecer com saldo zero;
- estoque não autorizado não deve receber o cadastro.
