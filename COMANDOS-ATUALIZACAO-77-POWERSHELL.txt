1. APLICAR E VALIDAR
--------------------

$repo = "C:\Users\TH\Documents\GitHub\estoque-superinfra"
$pacote = "$HOME\Downloads\atualizacao-77-revisoes-antes-confirmacao.zip"
$aplicador = "$HOME\Downloads\APLICAR-ATUALIZACAO-77.ps1"

if (!(Test-Path -LiteralPath $repo -PathType Container)) {
    throw "Projeto não encontrado em: $repo"
}

if (!(Test-Path -LiteralPath $pacote -PathType Leaf)) {
    throw "Pacote não encontrado em: $pacote"
}

if (!(Test-Path -LiteralPath $aplicador -PathType Leaf)) {
    throw "Aplicador não encontrado em: $aplicador"
}

Unblock-File -LiteralPath $aplicador

Set-ExecutionPolicy `
    -Scope Process `
    -ExecutionPolicy Bypass `
    -Force

& $aplicador `
    -Repo $repo `
    -Zip $pacote

2. ENVIAR AO GITHUB
-------------------

Set-Location "C:\Users\TH\Documents\GitHub\estoque-superinfra"

$arquivos = @(
    "frontend/src/components/OperationReviewModal.jsx",
    "frontend/src/pages/Receiving.jsx",
    "frontend/src/pages/Transfers.jsx",
    "frontend/src/pages/TechnicianInbox.jsx",

    "APLICAR-ATUALIZACAO-77.ps1"
)

git add -- $arquivos

git diff --cached --check

if ($LASTEXITCODE -ne 0) {
    throw "O Git encontrou problemas. Não faça o commit."
}

git status --short

git commit -m "Corrige e valida menus de revisao antes da confirmacao"

$branch = (git branch --show-current).Trim()

if ([string]::IsNullOrWhiteSpace($branch)) {
    throw "Não foi possível identificar a branch atual."
}

git push origin $branch

3. REDEPLOY
-----------

A alteração é somente de frontend.

1. concluir o push no GitHub;
2. fazer redeploy do frontend na Vercel;
3. aguardar a publicação;
4. sair e entrar novamente no sistema;
5. pressionar Ctrl+F5.

Não é necessário redeploy manual do Render.
Não existe migration de banco.

4. TESTE RÁPIDO
---------------

Após o redeploy:

1. abrir Entrada em Estoque e revisar um material com serial;
2. confirmar que os seriais aparecem na revisão;
3. abrir Transferências e revisar uma carga;
4. abrir a Caixa do Técnico e revisar uma solicitação;
5. confirmar que todos os materiais aparecem;
6. abrir Técnicos e revisar várias ferramentas;
7. remover os itens e confirmar que o botão final fica bloqueado;
8. voltar, preencher novamente e concluir uma operação de teste.
