$repo = "C:\Users\TH\Documents\GitHub\estoque-superinfra"
$pacote = "$HOME\Downloads\atualizacao-61-ordenacao-listas-recentes.zip"
$aplicador = "$HOME\Downloads\APLICAR-ATUALIZACAO-61.ps1"

if (!(Test-Path -LiteralPath $repo)) {
    throw "Projeto não encontrado em: $repo"
}

if (!(Test-Path -LiteralPath $pacote)) {
    throw "Pacote não encontrado em: $pacote"
}

if (!(Test-Path -LiteralPath $aplicador)) {
    throw "Aplicador não encontrado em: $aplicador"
}

Unblock-File -LiteralPath $aplicador

Set-ExecutionPolicy `
    -Scope Process `
    -ExecutionPolicy Bypass `
    -Force

& $aplicador `
    -Repo $repo `
    -Zip $pacote

5. CONFERÊNCIA RÁPIDA
---------------------

Em cada página, confirme que:
- o primeiro registro possui a data mais recente;
- registros da mesma data aparecem pelo maior ID primeiro;
- trocar de página não repete ou embaralha registros;
- filtros e buscas continuam funcionando;
- nenhum saldo ou status foi alterado pela atualização.
