1. APLICAR E VALIDAR
--------------------

$repo = "C:\Users\TH\Documents\GitHub\estoque-superinfra"
$pacote = "$HOME\Downloads\atualizacao-69-cadastrar-material-todos-estoques.zip"

if (!(Test-Path -LiteralPath $repo -PathType Container)) {
    throw "Projeto não encontrado em: $repo"
}

if (!(Test-Path -LiteralPath $pacote -PathType Leaf)) {
    throw "Pacote não encontrado em: $pacote"
}

if (!(Test-Path -LiteralPath $aplicador -PathType Leaf)) {
    throw "Aplicador não encontrado em: $aplicador"
}

Unblock-File -LiteralPath $aplicador

Set-ExecutionPolicy `
    -Scope Process `
    -ExecutionPolicy Bypass `
    -Force

& $aplicador `
    -Repo $repo `
    -Zip $pacote

4. TESTE CONTROLADO
-------------------

Cadastre um material de teste sem serial:

1. abrir Materiais / Estoque;
2. clicar em Novo material;
3. preencher SKU e nome;
4. em Onde cadastrar o material, escolher Todos os estoques operacionais autorizados;
5. conferir a lista de cidades exibida;
6. salvar;
7. abrir Detalhes do material;
8. confirmar saldo zero em cada estoque autorizado;
9. abrir Entrada em Estoque;
10. confirmar que o material aparece para receber quantidade em cada cidade.

Para material serializado:

1. marcar Exige número de série;
2. escolher Todos os estoques;
3. confirmar que os seriais iniciais ficam indisponíveis;
4. salvar com saldo zero;
5. registrar os seriais depois na Entrada em Estoque da cidade correta.
